# dj-assis — 아키텍처 (정본)

> "어떻게"의 정본. "무엇·왜"는 [`concept.md`](concept.md). 결정은 [`decisions.md`](decisions.md).
> 근거 표기: `[실측]` 이 리포 세션의 도구 결과 · `[문서]` 1차 공식 자료 · `[미확인]`.
> 날짜 없는 근거는 2026-10-18 기준이다. 표면 기능은 자주 바뀌므로 **쓰기 전에 도구 목록으로 다시 잰다.**
> 원자료는 [`research/20261018-foundation.md`](research/20261018-foundation.md).

## 1. 역할

| 역할 | 누구·어디 | 하는 일 |
|---|---|---|
| 사람 | 사용자, 안드로이드 Claude 앱 | 말하고, 결정한다 |
| 데스크 | dj-assis가 사는 세션 | 정리·인터뷰·컴파일·브리핑·전달. **직접 구현하지 않는다** |
| 워커 | Claude Code 클라우드 세션들 | 실제 작업. 각자의 리포·브랜치에서 |

## 2. 채널 — 무엇이 실제로 되나

| 방향 | 수단 | 상태 |
|---|---|---|
| 사람→데스크 | Code 탭 받아쓰기(한국어 베타) | `[문서]` Code 탭에는 음성 모드가 없고 받아쓰기만 |
| | 통합 Claude 음성 모드(양방향, 한국어 베타) | `[문서]` 2026-09-16. 프로젝트 지침 적용은 `[미확인]` |
| 데스크→사람 | 텍스트 + `AskUserQuestion` 선택 칩 | `[실측]` |
| | 세션 종료 알림(앱 푸시) | `[문서]` 클라우드 Code 세션 종료 시 |
| | 임의 시점 푸시 | `[문서]` Remote Control 연결 시에만 |
| | 아티팩트(시각 브리핑) | `[문서]` 앱에서 열람 가능. 페이지의 커넥터·저장의 안드로이드 동작은 `[미확인]` |
| 데스크→워커 | `create_session` · `send_message` | `[실측]` 동작. **공식 문서에 없는 인터페이스** — 바뀔 수 있다 |
| | 딥링크 `claude://code/new?q=` | `[문서]` 긴 본문 보존은 `[미확인]` |
| | `claude --cloud` · `claude -p --cloud <id>` | `[문서]` 셸이 있는 곳에서 |
| 워커→데스크 | `list_sessions` · `get_session` · `list_events` | `[실측]` |
| | `post_turn_summary`(status_category·needs_action·status_detail) | `[실측]` 표본 22개 중 19개에 존재 |

### 신뢰 경계

- 다른 세션의 기록은 하네스가 `untrusted` 래퍼로 감싸 준다 `[실측]` → **자료로만** 다룬다.
- 데스크가 보낸 메시지는 워커에게 "동료의 자료"로 도착하고, 워커는 그것만으로 파괴적 작업을 하지 않는다 `[문서: 도구 설명]`.
  → 비가역 결정은 사람이 해당 세션에서 직접 한다. 제약이 아니라 설계다(P4).
- 권한 프롬프트는 세션 간 메시지로 승인되지 않는다 `[문서]`.

### 안 되는 것 (지금)

- 아티팩트의 마이크 접근: 런타임 능력 목록에 없다 `[실측]`.
- Dispatch(폰→데스크톱 작업 위임): 신규 사용자에게 닫힘 `[문서]`.
- 자체 앱이 claude.ai 로그인으로 Claude Code를 대신 부르는 길: 제3자 제품에 허용되지 않음 `[문서]`.

## 3. 데스크 표면 선택

| 안 | 장점 | 약점 | 판정 |
|---|---|---|---|
| **B. Code 데스크 세션**(이 리포에서 연 세션) | 역방향 도구 전부 `[실측]`, 리포 스킬 자동 로드 `[실측]`, 스크립트·커밋 | 음성 출력 없음, 실행마다 세션 1개 | **1조각** |
| A. 통합 Claude 음성 데스크(claude.ai 프로젝트) | 양방향 음성, 메모리·커넥터 | 세션 도구 접근 `[미확인]`(S1) | 2조각 후보 |
| C. 아티팩트 콕핏 | 폰 전용 UI, 구독 내 | 페이지에서 워커 투입은 `[미확인]`, 안드로이드 기능 `[미확인]` | 표시 전용 후보 |
| D. 자체 앱 + API | 음성 UX 완전 통제 | API 별도 과금, 유지비 | 시드 |

1조각을 B로 두는 이유는 하나다: **역방향에 필요한 도구가 실측으로 다 있는 곳은 여기뿐이다.**
같은 절차를 A로 옮길 수 있는지는 S1이 가른다.

## 4. 조각 계획

원 구상 5요소(concept §2)와의 대응을 함께 적는다.

| 조각 | 무엇 | 구상 | 들어가는 조건 | 상태 |
|---|---|---|---|---|
| 1. 역방향 — 세션 브리핑 (`assis-inbox`) | 대기 세션 → 결정 카드 + 다음 방향 → 사람 답 → 정리된 전달 | ③④⑤ | — | **구현됨, 시험 1/3**(판정: 나음) |
| 3. 정방향 — 작업 접수 (`assis-intake`) | 말 → 사전 검토 → 인터뷰 → 의도 계약 → 지시서 → 투입 | ①② | 사용자 지시로 병행 착수(D-014) | **v0 구현됨, 시험 0** |
| 2. 음성 데스크 | 1·3조각 절차를 음성 표면으로 | ①④ | S1·S3 통과 | 대기 |
| 4. 체크포인트 운영 | 투입한 워커를 이정표마다 브리핑 | ③ | 3조각 시험 1건 | 대기 |

1조각과 3조각은 맞물린다: 지시서가 정한 **보고 형식**(결과 → 결정 1~2개 → 증거)이 그대로 결정 카드의 재료가 되고,
지시서 안의 **의도 계약 블록**이 4조각에서 "계약 대비 지금 어디인가"를 재는 기준이 된다.

### 1조각 흐름

```
사용자: "브리핑" (받아쓰기)
 └ 데스크: get_session(자기 id) → list_sessions → triage.py → (필요시) list_events(limit 100) → last_reply.py
     └ 결론 3줄 + 결정 카드(방금 활동은 한 줄) → AskUserQuestion (최대 4개/묶음, 묵은 대기는 1개로)
         └ 답 → 분류(결정/새 정보/생각/정지/넘기기) → 말로 한 답만 되읽기
             └ send_message(next, 정지만 now) · archive_session(정리 승인분) · 직접 항목은 링크
                 └ trials/ 익명 기록 → 커밋
```

### 3조각 흐름

```
사용자: "…해 줘" (받아쓰기, 두서없어도 됨)
 └ 데스크: 원문 보존 → 요청 가르기 → 요지 되말하기 → 깊이(L0~L3) 알림
     └ 사전 검토: list_repos · list_sessions(겹침) · (필요시) 대상 README/CLAUDE.md
         └ 인터뷰(L2·L3, 묶음당 ≤4, 추천 기본값) → 의도 계약 + 가정 목록 → 승인/고쳐서/보류
             └ 지시서 컴파일(왜 → 끝 상태·검증 → 범위·결정권 → 체크포인트 → 보고 형식 → 계약 원본 → 원문 부록)
                 └ create_session(대상 리포, tags dj-assis:intake) → 링크 + 체크포인트 안내
```

## 5. 상태와 기록

- **리포 단일 정본**이고 **공개 리포**다. 리포에는 제품과 일반화된 근거만 둔다(D-010).
- 데스크는 자기 상태를 따로 두지 않는다. 사실은 매번 `list_sessions`에서 새로 잰다(외운 값은 낡는다).
- 시험 기록은 `trials/`에 **익명으로** — 세션 제목·리포명·대화 원문 없이 범주·횟수·판정·개선점만.
- **의도 계약은 워커 세션 안에 산다**(D-015): 지시서에 `[의도 계약 vN]` 블록을 원본 그대로 넣는다.
  공개 리포에 사적 작업 내용을 남기지 않으면서, 별도 저장소 없이 나중에 `list_events`로 되찾을 수 있다.

## 6. 비용·한도

- 모든 표면이 계정 공용 사용량에서 나간다 `[문서]`. 비서 층은 사용량을 더한다.
- 데스크는 **요청받을 때만** 돈다. 폴링·예약 없음.
- 원자료를 그대로 읽지 않는다: `triage.py`가 목록을 91% 줄인다 `[실측]`. `list_events`는 `kinds` 필터·건수 상한.
- 워커 세션 명목 비용은 `external_metadata.usage.cost_usd`로 보인다 `[실측]` — 이후 브리핑 지표 후보.
